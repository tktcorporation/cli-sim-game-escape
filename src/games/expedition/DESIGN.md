# 遠征団 — 設計

## 核となる体験

放置は戦力を上げない。放置は出撃の燃料を貯める。
マップで節を切り拓き、詰まったら拠点で育て、またマップへ戻る。

```
放置 → 行軍糧が溜まる
    → マップ（1-1 → 1-2 → …）を攻略する
    → 詰まったら拠点で補給を使って育成する
    → またマップへ戻る
```

狙う感情は次の一文に集約する。

「次の節が見えている。詰まったら育てて、もう一度切り拓く。」

## ライフサイクル（二系統）

| 系統 | 役割 | プレイヤーがやること |
| --- | --- | --- |
| **メイン探索** | 章マップを進める | `1-1` / `1-2` / `1-3` / `1-4(Boss)` を順に攻略 |
| **強化ループ** | 詰まってから強くなる | 探索で得た**補給**を拠点で使い、団員のレベルを上げる |

- 放置は **行軍糧（燃料）だけ** を回復する。放置でレベルは上がらない
- 探索クリアではレベルは上がらない。**補給**だけが入る
- レベルアップは拠点の育成でのみ行う

この分離が「ボタンを押すだけ」を防ぐ。進む場所と強くなる場所が別動作になる。

## Milestone 1 で固定した判断

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| モジュール識別子 | `expedition` | 遠征の意味がコード上でも辿れる |
| 日本語タイトル | 遠征団 | 仮称を正式名として採用 |
| マップ単位 | 章-節（1章4節、末節ボス） | 放置ゲー共通の「次が見える進行」 |
| 成長の出口 | 拠点でのレベル上げ（補給消費） | 探索と強化を別ループにする |
| ソーシャル | Milestone 1 では入れない | ソロ核の面白さを先に測る |

## 三層の境界

| 層 | 役割 | 得ること | 直接やってはいけないこと |
| --- | --- | --- | --- |
| 放置 | 燃料タンク | 出撃するための行軍糧 | 攻撃力・HP・レベルを直接上げる |
| 本編（マップ） | 楽しさの本体＝探索進行 | 節クリア、補給、次の節の解禁 | 視聴するだけの完全フルオートだけにする |
| 成長（育成） | 永続強化 | 補給を消費してレベルを上げる | マップクリアで直接レベルを上げる |

- 戦闘は基本フルオートで1節1戦。任意の「援護」だけが手介入
- 敗退しても節は進まない。少量の補給だけ持ち帰り、育成へ誘導する

## UI 品質バー

**説明文でループを説かない。** 状況はマップ進行と主ボタンの状態で伝える。

- 拠点: **次の節**（`1-2` と道） / 出撃メンバー / 主CTA「▶ 1-2 に出る」
- 育成タブ: 補給残と団員ごとの「レベルアップ」主ボタン
- 探索中: 節ラベル・敵HP・仲間HP・直近ログ（何が起きているか見える）
- 敗退結果: 育成タブへ戻る導線

## 画面シェル

- **上部 HUD**: 行軍糧 / 下調べメモ / 補給 / いまの節 / フェーズ
- **下部ナビ**: `拠点` / `育成`
- **中央**: 拠点はマップ+メンバー+CTA。育成は強化。探索中は戦況

別 DOM は生やさない。オーバーレイは同一 `<pre>` 上への上書き描画。
