# 遠征団 — 設計

## 核となる体験

放置は戦力を上げない。放置は出撃の燃料を貯める。
戦役マップはタワーディフェンスの配置判断で切り拓く。
レベルは遊技場のメダルすごろくで上げる。

```
放置 → 行軍糧が溜まる
    → 戦役（1-1 → 1-2 → …）に出撃し、道に団員を置いて防衛する
    → クリアでメダルを得る
    → 遊技場ですごろくを回し、目的地到達でレベルを上げる
    → また戦役へ戻る
```

狙う感情は次の一文に集約する。

「配置で節を守り切る。足りなければ遊技場で育てて、もう一度切り拓く。」

## なぜこの二系統か

市場の放置少女系は「マップ進行」と「育成」を別動作にする。
出撃の中身だけはタワーディフェンスの配置判断にし、観戦だけの減算戦闘を避ける。
育成の出口は直接ボタンではなく、桃鉄／モノポリー系メダルすごろく（目的地まで残りN）にする。
すごろくは本編の節クリアを代替しない。レベルだけを渡し、マップ進行は戦役に残す。

## ライフサイクル

| 系統 | 役割 | プレイヤーがやること |
| --- | --- | --- |
| **戦役（メイン）** | 章マップを進める | 道に団員を配置し、ウェーブを防衛して `1-x` を攻略 |
| **遊技場（サブループ）** | 強くなる | メダルを張ってすごろくを進め、目的地で団員をレベルアップ |

- 放置は **行軍糧だけ** を回復する
- 戦役クリアではレベルは上がらない。**メダル**だけが入る
- レベルアップは遊技場の目的地到達でのみ行う

## 戦役出撃（TD）

1. 拠点でメンバー3人を揃えて出撃（行軍糧-1）
2. 短い道（5マス）へ団員を配置する
3. 敵ウェーブが門へ向かって進む。射程内の団員が自動攻撃する
4. 門の耐久が残って全ウェーブを凌げばクリア

役割は射程と役割で差を出す（説明しすぎない）。

| 役割 | 射程 | 振る舞い |
| --- | --- | --- |
| 盾 | 短い | 近い敵へ強い一撃 |
| 刃 | 長い | 遠い敵も削る |
| 癒 | 中 | 弱い攻撃＋敵を遅くする |

敗退しても節は進まない。少量のメダルだけ持ち帰り、遊技場へ誘導する。

## 遊技場（メダルすごろく）

参照するのは筐体そのものではなく、次の3点だけ。

- 目的地まで残りNが見える（桃鉄メダル／モノポリー・ザ・メダル）
- 張って進める短いループ
- 到達した瞬間の報酬（ここではレベルアップ）

| 項目 | 内容 |
| --- | --- |
| 通貨 | メダル（戦役で入手） |
| 操作 | メダルを消費してサイコロを振る |
| 目標 | 目的地マスに到達する |
| 報酬 | 団員を1人選んでレベル+1。盤面はリセット |

## 三層の境界

| 層 | 役割 | 得ること | 直接やってはいけないこと |
| --- | --- | --- | --- |
| 放置 | 燃料タンク | 行軍糧 | 攻撃力・レベルを直接上げる |
| 戦役 | 楽しさの本体＝マップ進行 | 節クリア、メダル | 視聴するだけの減算戦闘に戻す |
| 遊技場 | 永続強化 | レベル | すごろくで節を進める |

## UI 品質バー

**説明文でループを説かない。** 状況はマップ・配置盤・残りマスと主ボタンで伝える。

- 拠点: 次の節／出撃メンバー／「▶ 1-x に出る」
- 配置: 道のマスと未配置メンバー
- 防衛中: 道・敵位置・門の耐久・ウェーブ
- 遊技場: 残りマス・メダル・「サイコロを振る」・到達時のレベル選択
- 敗退結果: 遊技場へ戻る導線
