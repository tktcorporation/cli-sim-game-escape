# 遠征団 — 設計

## 核となる体験

放置は戦力を上げない。放置は出撃の燃料を貯める。
戦役マップはタワーディフェンスの配置判断で切り拓く。
レベルは遊技場のメダルプッシャーで上げる。

```
放置 → 行軍糧が溜まる
    → 戦役（1-1 → 1-2 → …）に出撃し、道に団員を置いて防衛する
    → クリアでメダルを得る
    → 遊技場でフィールドにメダルを落とし、押し出して光珠を落とす
    → 光珠が溜まったら団員をレベルアップ
    → また戦役へ戻る
```

狙う感情は次の一文に集約する。

「配置で節を守り切る。足りなければプッシャーで育てて、もう一度切り拓く。」

## なぜこの二系統か

市場の放置少女系は「マップ進行」と「育成」を別動作にする。
出撃の中身はタワーディフェンスの配置判断にし、観戦だけの減算戦闘を避ける。
育成の出口はボタン購入ではなく、ゲームセンターのメダル落とし（プッシャー）にする。
面白さは出目ではなく、「あと少しで落ちる」物理の手触りにある。
プッシャーは本編の節クリアを代替しない。レベルだけを渡し、マップ進行は戦役に残す。

## ライフサイクル

| 系統 | 役割 | プレイヤーがやること |
| --- | --- | --- |
| **戦役（メイン）** | 章マップを進める | 道に団員を配置し、ウェーブを防衛して `1-x` を攻略 |
| **遊技場（サブループ）** | 強くなる | レーンへメダルを投入し、押し出しで光珠を落としてレベルアップ |

- 放置は **行軍糧だけ** を回復する
- 戦役クリアではレベルは上がらない。**メダル**だけが入る
- レベルアップは光珠が規定数落ちたときのみ行う

## 戦役出撃（TD）

1. 拠点でメンバー3人を揃えて出撃（行軍糧-1）
2. 短い道（5マス）へ団員を配置する
3. 敵ウェーブが門へ向かって進む。射程内の団員が自動攻撃する
4. 門の耐久が残って全ウェーブを凌げばクリア

| 役割 | 射程 | 振る舞い |
| --- | --- | --- |
| 盾 | 短い | 近い敵へ強い一撃 |
| 刃 | 長い | 遠い敵も削る |
| 癒 | 中 | 弱い攻撃＋敵を遅くする |

敗退しても節は進まない。少量のメダルだけ持ち帰り、遊技場へ誘導する。

## 遊技場（メダルプッシャー）

参照するのは筐体の物理そのものではなく、次の3点だけ。

- フィールド上の山と端の「落ちそう」が見える
- どこに落とすかの軽い判断
- 光珠が落ちた瞬間の報酬（レベル）

| 項目 | 内容 |
| --- | --- |
| 通貨 | メダル（戦役で入手） |
| 操作 | レーンを選んで1枚投入（押し板は自動で往復） |
| 落下 | 手前端から落ちたメダルは払い出し。光珠はレベルゲージへ |
| 報酬 | 光珠が規定数で団員を1人選んでレベル+1 |

玉響（パチンコ）とは別物にする。釘読み・台選びではなく、山の押し合いと端の落下だけを楽しむ。

## 三層の境界

| 層 | 役割 | 得ること | 直接やってはいけないこと |
| --- | --- | --- | --- |
| 放置 | 燃料タンク | 行軍糧 | 攻撃力・レベルを直接上げる |
| 戦役 | 楽しさの本体＝マップ進行 | 節クリア、メダル | 視聴するだけの減算戦闘に戻す |
| 遊技場 | 永続強化 | レベル | プッシャーで節を進める |

## UI 品質バー

状況は **点描の盤面** と **短いラベル** の両方で伝える。記号だけに寄せすぎない。

- 銘標: Braille 飾り＋「遠征団」。figlet ではなく端末向けの小さなワードマーク
- 拠点: 戦役マップ（節名つき）／編成詳細（役割・Lv）／主CTA `▶ 出撃 1-1 斥候道`
- 配置・防衛: Canvas+Braille の道（縁・門・湧出）。操作ヒントと「防衛開始」などの文言
- 遊技場: プッシャー筐体の点描＋「投入レーン」「光珠あとN」
- HUD: `行軍糧` / `メダル` / `光珠` のラベル付きピクトと「次: …」目標行
- 下部ナビ: `拠点 ⌂` / `遊技場 ◎`

## 画面シェル（Everlight 型）

常夜灯と同じ組み方にする。領域は `compute_*_layout` で一度だけ決め、描画関数は受け取った `Rect` だけを触る。

| 領域 | 内容 |
| --- | --- |
| Header | 銘標・節名・資源ラベル・次の目標 |
| Body | 拠点マップ / プッシャー / 配置・防衛の Canvas 面。ワイド時は右に行軍情景 |
| Nav | `拠点 ⌂` / `遊技場 ◎`（出撃中は非操作） |
| Modal | 光珠レベル選択。`Clear` で同一 `<pre>` 上に上書き |

操作の粒度はセル単位。配置スロット・投入レーンは `ClickableGrid`、ボタンは `Clickable` / `TabBar`。
ワールド座標（`WORLD_*` / `PUSH_WORLD_*`）と端末セルは分離し、描画位置は Canvas 側で細かく制御する。

別 DOM は生やさない。オーバーレイは同一 `<pre>` 上への上書き描画。
