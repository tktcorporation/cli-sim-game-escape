# 遠征団 — 設計

## 核となる体験

放置は戦力を上げない。放置は出撃の燃料を貯める。
燃料を使って短い遠征本編を遊び、その結果でのみ団が強くなる。

```
放置 → 行軍糧 / 下調べメモが溜まる
     → 燃料で遠征ランを遊ぶ
     → 遠征の成績で絆が伸びる
```

狙う感情は次の一文に集約する。

「帰ってきたら遠征の燃料が溜まっている。消化したくなる。遊んだ結果、団が一つ強くなる。」

## Milestone 1 で固定した判断

| 項目 | 決定 | 理由 |
| --- | --- | --- |
| モジュール識別子 | `expedition` | 遠征の意味がコード上でも辿れる |
| 日本語タイトル | 遠征団 | 仮称を正式名として採用 |
| 1ランの長さ | 短い（数ノード） | 燃料消化の快感を先に検証する |
| 成長の最初の1本 | 個人ヒーローの絆 | 編成判断と直結する |
| ソーシャル | Milestone 1 では入れない | ソロ核の面白さを先に測る |

## 三層の境界

| 層 | 役割 | 得ること | 直接やってはいけないこと |
| --- | --- | --- | --- |
| 放置 | 燃料タンク | 出撃するための資源 | 攻撃力・HP・装備本体を直接上げる |
| 本編 | 楽しさの本体 | 編成と判断の手応え | 視聴するだけの完全フルオートだけにする |
| 成長 | 永続報酬 | 本編の成績からのみ強くなる | ログインや放置時間そのもので戦力を上げる |

- 行軍糧の回復速度は絆合計で少し速くなる（間接のみ）
- 攻撃力・HP は遠征クリア（または敗退時の僅かな）絆報酬でのみ伸びる
- 戦闘は基本フルオートで完走する。任意の「援護」だけが手介入（使わなくても進む）

## なぜこの形か

- 編成だけの連戦だと一回性が薄くなりやすい
- 分岐だけのローグライトだと団の育成感が薄くなりやすい
- 本編の手介入は「任意の援護」に絞り、必須の分かれ道選択は置かない

## 成長の出口（Milestone 1）

到達した遠征の成績 → 参加者ヒーローの絆。
絆は ATK/HP を上げ、行軍糧の回復速度と上限にも間接効果を持つ。
放置時間そのものでは絆は増えない。


## 本編の操作

遠征中は自動でノードを進み、全滅かボス突破で帰還する。
任意ボタン「援護」を1回だけ押すと回復＋追い打ちになる。押さなくても完走する。

## UI 品質バー

端末セルでも、ネイティブ放置ゲーと同程度の体験を目指す。
**説明文でループを説かない。** 状況はビジュアルと主ボタンの状態で伝える。

- 拠点の3点セット: **行き先**（層と道） / **出撃メンバー** / **主CTA**
- 主CTAはフル幅。糧ありなら「遠征に出る」、無しなら回復バー
- 編成は副次（メンバー枠タップ）。主ボタンはワンタップ出撃
- 選択中タブは色だけでなく `●` でテキストでも分かる
- 遠征中はステータスにフェーズ（編成中 / 遠征中 / 帰還）を出す
- 「やること」「※放置では…」のような説明段落は拠点に置かない

## 画面シェル（M1 UI）

- **上部 HUD（常設）**: 行軍糧 / 下調べメモ / 絆 / 到達層 / フェーズ
- **下部ナビ（常設）**: `拠点` / `団員`
- **中央**: 拠点は行き先+メンバー+CTA。遠征中は同じ枠にシート/自動戦闘（任意援護）/結果

別 DOM は生やさない。オーバーレイは同一 `<pre>` 上への上書き描画。
